# Smart Outfit Showcase

Die Idee eines digitalen Kleiderschranks erkunden.

**Status:** Statischer Prototyp. **Technik:** HTML, CSS, JavaScript.

[Demo öffnen](https://lilarosa.github.io/frontend-projects/projects/06_smart-outfit/) · [Zur Übersicht](../../README.md)

## Dateien und Start

- `index.html`: Startseite
- `style.css`: Gestaltung
- `app.js`: Interaktion

Für eine lokale Vorschau den Server wie in der [Hauptanleitung](../../README.md#lokal-öffnen) starten und diesen Projektordner im Browser öffnen.
