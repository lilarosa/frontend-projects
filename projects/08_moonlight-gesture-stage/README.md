# Moonlight Gesture Stage · 月光变身

Eine interaktive Sailor-Moon-Fandemo mit Mondlicht, animierten Sternspuren und drei Posen. Die Oberfläche ist auf Chinesisch.

[Demo öffnen](https://lilarosa.github.io/frontend-projects/projects/08_moonlight-gesture-stage/)

| Handgeste | Animation | Taste |
|---|---|---|
| Handfläche öffnen | Mondlicht-Verwandlung | 1 |
| Zeige- und Mittelfinger als V halten | Sailor Moons Grußpose | 2 |
| Daumen und Zeigefinger zusammenführen | Fliegendes Mond-Diadem | 3 |

Die drei Schaltflächen starten dieselben Animationen. Für die Handsteuerung in der HTTPS-Demo auf „开启摄像头“ klicken und Kamerazugriff zulassen. MediaPipe verarbeitet die Kamerabilder direkt im Browser. Die Handerkennung benötigt WebGL.
